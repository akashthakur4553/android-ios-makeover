# YouTube ads — honest options

DNS blocking (Phase 7) **cannot** remove YouTube in-app ads: they come from the same servers as videos.

| Option | Effort | Notes |
|---|---|---|
| YouTube Premium | pay | Official, background play, no ads |
| Brave browser (youtube.com) | easy | Built-in ad blocker; background play works in Brave |
| ReVanced (patched YouTube) | medium | Open source (github.com/ReVanced). Needs ReVanced Manager + a matching YouTube APK + GmsCore for login. **Against YouTube's Terms of Service**; updates sometimes break it. Only do this if the user explicitly asks after hearing this. Download only from the official ReVanced site/GitHub. |

Never download pre-patched YouTube APKs from random sites (malware risk).
